# 网页原型（mock）· 原型说明

- 打开：直接用浏览器打开 `index.html`，或在本目录运行 `python3 -m http.server` 后访问。无构建、无外部 CDN。
- 产品名「Assistant」为**占位代号**（候选「同舟」未定）；图标、头像为美术占位，引用 `assets/`（美术文件未改动）。
- 视觉：A 原生简洁 + C 专属色（产品 #FF6B4A / 开发 #8B5CF6 / 美术 #F59E0B / 项目经理 #14B8A6），深色参考 B，侧栏底部可切换浅/深色。
- 假设：模型走中台统一接入；定时任务和群聊进 MVP；定时任务由中台托管，遇需审批操作暂停于断点，批准后续跑。
- 全部 mock：无真实模型、中台、文件读写、邮件。回复为关键词脚本（删 / 发、邮件 / 出错）。
- 审批卡下的「演示控制」仅用于评审演示五种状态；对话头部「审批卡五态演示」一键插入五张卡。
- 删除、对外发送、执行命令三项「自动」档锁定不可选。
- 路由：`#chat/<product|dev|art|pm>`、`#group`、`#assistants`、`#tasks`、`#settings`、`#notes`；`?theme=dark` 深色，`?nostream=1` 关闭打字效果（截图用）。
- 未覆盖：记忆、审计日志/撤销页、系统通知、Mac 原生交互。
